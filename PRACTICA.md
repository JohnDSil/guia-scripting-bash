
# Cuaderno de práctica de Bash

## Instrucciones

- Resuelve los ejercicios en orden.
- Guarda tus scripts en archivos `.sh`.
- Utiliza los capítulos y ejemplos como referencia.
- Anota las dudas y los resultados.
- Consulta `SOLUCIONES.md` después de intentarlo.

## Nivel 1. Introducción y salida

- [ ] 1. Crea un script que muestre `Hola, mundo`.
- [ ] 2. Muestra tres mensajes en líneas separadas.
- [ ] 3. Modifica el texto de un mensaje.
- [ ] 4. Ejecuta un script con Bash.

## Nivel 2. Variables y entrada

- [ ] 5. Crea una variable llamada `nombre` y muestra su valor.
- [ ] 6. Solicita un nombre con `read` y saluda al usuario.
- [ ] 7. Muestra la fecha utilizando sustitución de comandos.
- [ ] 8. Prueba la diferencia entre comillas simples y dobles.
- [ ] 9. Consulta las variables del entorno con `env`.

## Nivel 3. Operaciones

- [ ] 10. Suma dos variables con `let`.
- [ ] 11. Realiza una resta con `$((...))`.
- [ ] 12. Multiplica dos números.
- [ ] 13. Utiliza `expr` para sumar dos números.
- [ ] 14. Utiliza `bc` para realizar una división decimal.
- [ ] 15. Prueba `basename` con una ruta de ejemplo.

## Nivel 4. Condicionales

- [ ] 16. Pide un número y comprueba si es positivo.
- [ ] 17. Distingue entre número positivo, negativo y cero.
- [ ] 18. Comprueba si existe un archivo regular.
- [ ] 19. Crea un menú de opciones utilizando `case`.
- [ ] 20. Añade una respuesta para opciones no reconocidas.

## Nivel 5. Bucles

- [ ] 21. Muestra los números del 1 al 10 con `for`.
- [ ] 22. Repite una instrucción con `while`.
- [ ] 23. Repite una instrucción con `until`.
- [ ] 24. Utiliza `break` para salir de un bucle.
- [ ] 25. Utiliza `continue` para saltar a la siguiente iteración.
- [ ] 26. Muestra varios valores de `RANDOM`.

## Nivel 6. Parámetros y funciones

- [ ] 27. Muestra el primer parámetro de un script.
- [ ] 28. Muestra cuántos parámetros se han recibido.
- [ ] 29. Crea una función que muestre un saludo.
- [ ] 30. Construye un menú con `select`.

## Nivel 7. Depuración

- [ ] 31. Comprueba la sintaxis de un script con `bash -n`.
- [ ] 32. Observa su ejecución con `bash -v`.
- [ ] 33. Observa su ejecución con `bash -x`.
- [ ] 34. Consulta el código de retorno mediante `$?`.
