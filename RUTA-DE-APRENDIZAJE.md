
# Ruta de aprendizaje de Bash

## Cómo utilizar esta ruta

Sigue las etapas en orden. Marca cada casilla cuando hayas leído el capítulo, probado los ejemplos y realizado los ejercicios.

## Etapa 1. Primeros pasos

- [ ] Leer el capítulo 1.
- [ ] Crear y ejecutar el primer script.
- [ ] Practicar `echo`.
- [ ] Resolver los ejercicios de introducción.

**Objetivo:** crear un script sencillo y mostrar mensajes.

## Etapa 2. Entrada, salida y variables

- [ ] Leer el capítulo 2.
- [ ] Practicar `read`.
- [ ] Crear y consultar variables.
- [ ] Probar la sustitución de comandos.
- [ ] Reconocer las variables especiales.

**Objetivo:** recoger datos y utilizar valores en un script.

## Etapa 3. Operaciones

- [ ] Leer el capítulo 3.
- [ ] Practicar `let`.
- [ ] Practicar `$((...))`.
- [ ] Probar `expr`.
- [ ] Probar `bc`.
- [ ] Practicar `basename`.

**Objetivo:** construir expresiones y mostrar resultados.

## Etapa 4. Condicionales

- [ ] Leer el capítulo 4.
- [ ] Crear una estructura `if`.
- [ ] Añadir alternativas con `else` y `elif`.
- [ ] Practicar pruebas de archivos.
- [ ] Crear una selección con `case`.

**Objetivo:** ejecutar instrucciones según condiciones.

## Etapa 5. Bucles

- [ ] Leer el capítulo 5.
- [ ] Practicar `for`.
- [ ] Practicar `while`.
- [ ] Practicar `until`.
- [ ] Probar `break` y `continue`.
- [ ] Consultar `RANDOM`.

**Objetivo:** repetir instrucciones de forma controlada.

## Etapa 6. Parámetros y funciones

- [ ] Leer el capítulo 6.
- [ ] Practicar `$1` y `$#`.
- [ ] Crear una función.
- [ ] Practicar `select`.
- [ ] Consultar códigos de retorno.

**Objetivo:** reutilizar instrucciones y recibir argumentos.

## Etapa 7. Depuración y dialog

- [ ] Leer el capítulo 7.
- [ ] Probar `bash -n`.
- [ ] Probar `bash -v`.
- [ ] Probar `bash -x`.
- [ ] Revisar los ejemplos de `dialog`.

**Objetivo:** reconocer las herramientas de depuración del material.

## Etapa 8. Práctica final

- [ ] Completar `PRACTICA.md`.
- [ ] Consultar `SOLUCIONES.md` después de intentar los ejercicios.
- [ ] Completar `PROYECTO-FINAL.md`.
- [ ] Repasar los errores frecuentes.

## Evaluación personal

- ¿Puedo escribir un script desde cero?
- ¿Sé interpretar un condicional?
- ¿Puedo elegir el bucle adecuado entre los estudiados?
- ¿Sé utilizar parámetros y funciones?
- ¿Sé comprobar la sintaxis de un script?
